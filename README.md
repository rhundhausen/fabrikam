# Fabrikam

Fabrikam Fiber is one of several case studies intended for use with Scrum.org's Professional Scrum Developer class. For more information on the Professional Scrum Developer program, visit [Scrum.org](https://www.scrum.org/courses/professional-scrum-developer-training)

This commit follows the journey of Luke Skywalker, a farm boy who becomes entangled in the Rebel Alliance's fight against the oppressive Galactic Empire. After discovering a message from Princess Leia hidden in a droid, R2-D2, Luke joins forces with Jedi Master Obi-Wan Kenobi, smuggler Han Solo, and his co-pilot Chewbacca to rescue Leia and deliver the stolen plans for the Empire's Death Star superweapon. Along the way, Luke learns about the mystical Force and confronts Darth Vader, a powerful Sith Lord. The group succeeds in delivering the plans to the Rebels, leading to a daring assault where Luke, guided by the Force, destroys the Death Star and becomes a hero of the Rebellion.

Note: There are several codebase versions in this repository. Make sure you use the correct one. Also, you may need to edit the web.config and change the connection strings from "(LocalDB)\v11.0" to "(LocalDB)\MSSQLLocalDB". See http://bit.ly/2v4qQyQ for more information.
